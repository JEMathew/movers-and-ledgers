## Intake limits retained

At most nine expanded files, 256 KiB per expanded file, 2 MiB expanded package, 3 MiB HTTP body, 1,000 records per CSV, 32 columns per CSV, 8,192 characters per cell and 100:1 ZIP ratio. Supported required names: customers.csv, vendors.csv, accounts.csv, products.csv, invoices.csv, bills.csv, transactions.csv, configuration.json. Optional metadata.json. UI must not imply a browser-local validation result authorizes upload or provider writes.

## Evidence and release rule

The [traceability matrix](promise-traceability.md) supplies source and test anchors. The submission acceptance/evidence manifest must record actual test execution and deployment/user acceptance for the candidate commit. Existing test files are evidence of coverage intent, not proof those tests passed in this sprint. Unsupported promises stay open with a backlog link and explicit No-Go for that activation.
