## Working public Beta screenshot

[`movebooks-live-beta.jpg`](movebooks-live-beta.jpg) is a genuine browser capture of
<https://movebooks-si.web.app/> taken on **10 October 2026 (IST)**, signed out, in the
current dark appearance. It shows the deployed public landing page, including the
synthetic-data notice and migration entry point. The on-page journey is an overview,
not live progress. This capture does not demonstrate an authenticated workflow or
revalidate migration, financial controls or production readiness.

The original browser JPEG is committed directly: 889 × 924 pixels, 62,875 bytes
(about 61 KiB). No screens, controls, data or artwork were fabricated or composited.
The compact JPEG avoids adding the existing 968 KiB presentation PNG to the hero.
The README links the screenshot to the canonical live product.
