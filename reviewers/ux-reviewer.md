# UX reviewer

Apply the shared contract in [README](README.md).

Review whether each meaningful screen explains what is happening, why, and the next action. Examine comprehension, trust, control, progress, risk, cognitive load, status semantics, consequential-decision context, feedback, empty/loading/error/recovery states, responsive behavior, keyboard use, focus, assistive semantics, contrast, and reduced motion. Preserve the shared light/dark design system and never accept color-only state.
